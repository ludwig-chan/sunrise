## 功能概述

在游戏发展路线的**第二阶段**引入卡牌系统，玩家可以收集、组建卡组，并在后续阶段中与其他玩家进行卡牌对战。

## 核心功能点

### 卡牌基础系统
- [ ] 卡牌数据结构设计（类型、费用、效果、稀有度、描述）
- [ ] 卡牌获取途径（探索掉落、资源合成、任务奖励）
- [ ] 卡牌收藏界面（展示已获得的卡牌）

### 卡组管理
- [ ] 卡组构建界面（拖拽组牌）
- [ ] 卡组容量限制（每阶段上限不同）
- [ ] 稀有卡数量限制

### 对战系统
- [ ] 回合制对战逻辑（每回合 30 秒思考时间）
- [ ] 同时出牌机制
- [ ] 克制关系设计（攻击/防御/法术等类型）
- [ ] 翻盘机制（落后方增益 + 特殊翻盘卡）

### 卡牌稀有度

| 稀有度 | 获取难度 | 特点 |
|--------|----------|------|
| 普通卡 | 容易 | 基础效果 |
| 稀有卡 | 中等 | 特殊效果 |
| 传说卡 | 极难 | 独特机制 |

## 各阶段解锁内容

- **第二阶段**：解锁基础卡牌系统，获得初始卡组（生存类卡牌）
- **第三阶段**：解锁进阶卡牌（建筑、防御类卡牌），开启初级 PVP 对战
- **第四阶段**：解锁科技卡牌，开启区域争夺战
- **第五阶段**：解锁太空探索卡牌，开启星际对战系统

## 技术实现方向

- 卡牌数据以 JSON 配置文件管理，方便扩展
- 对战逻辑在联机模式下需服务端裁决，单机模式可纯前端模拟
- 建议新增 src/stores/cards.ts 管理卡牌状态
- 建议新增 src/components/cards/ 目录存放卡牌相关组件
