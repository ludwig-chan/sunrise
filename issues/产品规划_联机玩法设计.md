## 功能概述

在游戏发展路线的**第三阶段**引入联机玩法，支持多名玩家在同一世界中互动、贸易、对战与合作。

## 核心功能点

### 多人在线基础
- [ ] 玩家账号与身份系统（登录/注册）
- [ ] 服务器端游戏状态存储（当前为纯本地 localStorage）
- [ ] 玩家列表与在线状态展示

### 社交互动
- [ ] 玩家之间的贸易系统（资源/道具交换）
- [ ] 世界内聊天频道
- [ ] 好友系统与私信

### 合作/对抗玩法
- [ ] 联盟组建：弱小方结盟共同对抗强者
- [ ] PVP 对战入口（结合卡牌系统）
- [ ] 区域争夺战（第四阶段）

## 技术方案初步规划

- 后端：需要引入服务端（如 Node.js + WebSocket / Supabase Realtime）
- 状态同步：将 Pinia store 中的核心状态同步到服务器
- 数据库：玩家数据、世界状态持久化
- 安全：防止客户端作弊，关键操作需服务端校验

## 里程碑

- 阶段三解锁：贸易系统 + 基础聊天
- 阶段四解锁：区域争夺战 + PVP
- 阶段五解锁：星际联盟系统
